# Аудиопримеры переходов

На [сайте](https://deepback.github.io/ladio/#transitions) подготовлены три места: обмен спектром, эхо и удержание грува. Сейчас в них нет опубликованных записей. Анимации объясняют конструкцию; они не доказывают слышимое качество конкретного микса.

## Что записать

Для одной пары сохранить исходные фрагменты A и B, обычное наложение и результат LADIO. Включить подведение, полный вход и хотя бы одну следующую фразу B. Согласовать громкость всех вариантов и описать способ: например, одна и та же целевая интегральная громкость, без независимого подъёма пика каждого фрагмента.

Запись должна позволять услышать, что изменил эффект. Для эхо полезно отдельно проверить возврат после ухода сухого A; для лупа — точку выхода; для фильтра — полный диапазон B к его входу.

Сохранять рядом идентификатор сцены, seed, версию модели/фронтенда, выбранные точки и отчёт рендера. Не выдавать синтетический пример с известной разметкой за проверку автоматического анализа реальной песни.

## Как добавить на сайт

1. Поместить разрешённые к публикации MP3, OGG, M4A или WAV в `docs/audio/`. Для сайта достаточно сжатых прослушиваемых фрагментов; гигантские PCM-окна не нужны.
2. Открыть `docs/audio/examples.json`. У записи с нужным `scene` заполнить `title`, `source`, `license`, `level_matching` и три пути в `audio`.
3. Поставить `published: true`. Все три файла и сведения о происхождении должны быть готовы одновременно.
4. Запустить `python3 scripts/verify_docs.py`, открыть сайт и прослушать варианты.

Пути задаются относительно `docs/index.html`, например `audio/spectral-ladio.mp3`. Три ключа: `originals` — исходные фрагменты, `crossfade` — простое наложение, `ladio` — результат движка. Плееры появляются автоматически при выборе сцены; запуск одного останавливает другие.

Публиковать собственную музыку, материал с подходящей открытой лицензией либо с разрешением правообладателя. Указать автора и источник. Пустое место не заменять фиктивной кнопкой воспроизведения.
