# C: использование установленного SDK

Соберите и установите SDK, затем настройте этот отдельный проект с `-DCMAKE_PREFIX_PATH=/path/to/install`. Соберите и запустите `ladio_consumer`: он проверяет установленный пакет и C ABI без внутренних C++-заголовков. Правила потоков описаны в публичном заголовке; аудиоколбэк предоставляет приложение.
