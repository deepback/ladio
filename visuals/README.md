# Анимации LADIO

Три восьмисекундные схемы: `Spectral` — обмен спектром, `Echo` — отдельный хвост дилея, `Loop` — удержание грува перед входом B. Исходник — `src/Root.tsx`. Размер 1200 × 680, 24 кадра/с. Значения условные; это объяснение музыкальной конструкции, а не запись конкретного аудиорендера.

```sh
npm ci
npm run dev -- --no-open
```

Открыть адрес Remotion Studio из терминала. Для готовых файлов из корня репозитория:

```sh
python3 scripts/render_visuals.py
```

Нужен FFmpeg в PATH. На выходе — три MP4, три GIF шириной 720 пикселей при 12 кадрах/с и три PNG-постера в `docs/assets`. Сайт использует MP4, README — GIF. Тяжёлые промежуточные кадры в Git не добавляются.
